# taskmanager_DevOps2

Esse sistema é um sistema de organização diaria baseado no kanbam, ele esta ligado com a agenda do seu dispositivo então você pode fazer um lembrete de algo para daqui a 10 ou 20 dias.
Também é possivel personalizar o lembrete, por exemplo: Reunião com algum socío pode ter mais relevancia, então ficara com uma cor com mais destaque e com uma notficação personalizada.

## Funcionalidades

- Conclusão de tarefas

- Definição de prioridade das tarefas
