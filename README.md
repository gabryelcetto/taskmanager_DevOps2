# taskmanager_DevOps2

Este sistema é um sistema de organização diária baseado no Kanban. Ele está ligado à agenda do seu dispositivo, então você pode fazer um lembrete de algo para daqui a 10 ou 20 dias. Também é possível personalizar o lembrete. Por exemplo: uma reunião com algum sócio pode ter mais relevância, então ficará com uma cor com mais destaque e com uma notificação personalizada

## Funcionalidades

- Conclusão de tarefas

- Definição de prioridade das tarefas
